# Contribuir

Para cada recurso: abra uma issue com ID F-xxx, escreva teste que falhe, implemente o mínimo, valide no Windows, atualize `docs/backlog/TAREFAS.json` e `docs/ACOMPANHAMENTO.md`. Separe alterações por branch, sem force-push.

Não adicione código ou assets copiados de software fechado. Não acesse clipboard, microfone, webcam ou rede sem consentimento.
