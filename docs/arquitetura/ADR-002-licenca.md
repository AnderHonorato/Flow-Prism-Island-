# ADR-002 — Licenciamento

Decisão: produto independente; licença MIT para o código original deste repositório.

Sem cópia, fork nem derivação do código GPL do HeyyCzer nesta primeira fatia. Não incorporar partes de DynamicWin, Seelen UI, Notchify, MyDockFinder, WindowBlinds ou outros sem auditoria de licença.

Se o projeto posteriormente reutilizar código GPL, reavaliar a licença e cumprir as obrigações de distribuição correspondentes. Créditos de ideias e inspirações não implicam endosso por autores terceiros.
